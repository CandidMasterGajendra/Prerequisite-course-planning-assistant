# Project write-up: working notes

The sourced OSU pilot now has provenance-preserving ingestion from 52 distinct official catalog pages (48 course, two program, two policy), a local embedding index, 27 encoded reviewed rules, five deliberately unresolved rules, a bounded course planner, retrieved source citations, and 27 labeled deterministic checks. Citation validation checks passage identity, multi-course chain evidence, and program-course membership; it is not a substitute for manually verifying rule interpretation.

The corrected assessment evaluation contains the required 25-query category mix plus two planning cases. All 15 eligibility decisions, five abstentions, five multi-course evidence checks, and two plan-credit checks pass; citation coverage is 100% on the 22 responses that make catalog claims. These are development regression results against manually encoded rules, not independent real-world accuracy.

The pilot now has a LangGraph workflow with explicit intake, retrieval, rule decision, optional structured GPT wording, and verification stages. It runs without an API key using a labeled template fallback. A live evaluation runner and manual support-review rubric are in `src/evaluate_generation.py` and `GENERATION_EVAL.md`. With a local key, the first development-set live run made 17 GPT calls: all 17 drafts passed the structural verifier, while eight clarification or abstention cases bypassed GPT. Codex audited the drafts against the cited passages and student profiles, but independent human review and held-out testing remain pending. See `EVALUATION_RESULTS.md`. Structural verification cannot prove that every generated sentence is supported by its cited passage.

A local web demo now collects a student profile and displays the five required output sections with citations. Remaining work for a public portfolio release is independent human review, broader rule coverage beyond the bounded pilot, and publishing the repository and demo. See `README.md` for exact scope and run commands.
